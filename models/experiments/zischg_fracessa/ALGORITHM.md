# Zischg–FracESSA

Classification: coposit-created strict-copositivity model combining FracESSA's exact first-order support search with the Level 2
negative-graph reduction derived from Zischg and Bomze.

Public mode boundary: this coposit-created model supports only `strictly_copositive`. Calling
`solve(A, copositivity_mode::copositive)` throws `std::invalid_argument` instead of applying strict rules to a non-strict query.

## Idea In Plain Language

The FracESSA model maximizes $Q=-A$ on the standard simplex and decides whether every exact KKT candidate payoff is negative. This
variant skips a generated support before its KKT solve when the negative-entry graph of $A$ induced by that support is disconnected.
Cross-component entries of $A$ are nonnegative, so cross-component entries of $Q$ are nonpositive. A disconnected support cannot be
the only place where a nonnegative maximum proving failure exists: one of its connected components contains a nonnegative witness.

Connected supports retain FracESSA's exact reduced solve, outside-payoff inequalities, payoff-sign exit, and forbidden-superset
pruning. The complete matrix is never split, so the reduction is Level 2 only.

## Simplex Formulation

For

\[
Q=-A,\qquad \Delta_n=\{x\geq0:\mathbf1^Tx=1\},
\]

homogeneity gives

\[
A\text{ strictly copositive}
\iff \min_{x\in\Delta_n}x^TAx>0
\iff \max_{x\in\Delta_n}x^TQx<0.
\]

Every global maximum is a first-order KKT point. For support $S$, an accepted candidate satisfies

\[
Q_Sx_S=u\mathbf1,\qquad \mathbf1^Tx_S=1,\qquad x_S>0,
\qquad (Qx)_k\leq u\quad(k\notin S).
\]

Its exact objective value is $u$. A nonnegative $u$ rejects strict copositivity immediately.

## Why Disconnected KKT Supports May Be Skipped

Let the induced negative graph $G^-(A)[S]$ have components $C_1,\ldots,C_r$. For $s\ne t$,

\[
A[C_s,C_t]\geq0
\quad\text{and therefore}\quad
Q[C_s,C_t]\leq0
\]

entrywise. Write $x_S$ as component masses $\alpha_t$ times normalized component vectors $y_t$. Then

\[
x^TQx
=\sum_t\alpha_t^2y_t^TQ[C_t,C_t]y_t
+2\sum_{s<t}\alpha_s\alpha_t y_s^TQ[C_s,C_t]y_t,
\]

and the cross terms are nonpositive. If this value is nonnegative, at least one component restriction has nonnegative value. Thus a
failure witness exists on a strictly smaller connected support. Equivalently, among global maximizers with nonnegative value, choose
one with minimum support; its negative graph must be connected. The traversal cannot lose the decisive payoff by omitting
disconnected supports.

When the global value is negative, a disconnected support can have a larger but still negative value because distributing mass can
reduce positive $A$ component terms. Omitting that value is harmless because this model decides only its sign, not the numerical
minimum.

Skipping a disconnected KKT support also means it creates no forbidden-superset rule. That can only cause more later supports to be
visited. It cannot prune a valid decisive support.

## Exact Candidate Solve

Choose the lowest support index $m$ as reference and write $x=e_m+Zy$, where the columns of $Z$ are $e_i-e_m$ for the other support
indices. The common-payoff equations reduce to

\[
Hy=r,\qquad H=Z^TQ_SZ,\qquad r=-Z^TQ_Se_m.
\]

For non-reference indices $i,j$,

\[
H_{ij}=Q_{ij}-Q_{mj}+Q_{mm}-Q_{im},\qquad r_i=Q_{mm}-Q_{im}.
\]

One fraction-free LDLT factorization and solve produces integer probability numerators with a positive common denominator. Singular
systems and nonpositive support probabilities are rejected. Exact support and outside payoffs then enforce the full KKT
inequalities. No floating arithmetic or second-order condition is used.

## Support Traversal And Pruning

Supports are generated by increasing cardinality and numeric-mask order using packed multiword supports. Accepted KKT supports are
activated as forbidden subsets only at the next cardinality. A later strict superset is skipped because symmetry and the KKT
inequalities imply that its candidate payoff cannot exceed the earlier candidate payoff. This retains the base FracESSA pruning
proof.

For order-four-or-larger supports, the Zischg connectivity test runs before the reduced KKT system is built. The adjacency graph is
built once. A complete negative graph or a root adjacent to the rest of the support accepts connectivity immediately; otherwise a
reusable packed breadth-first search checks only the graph induced by the current support. Orders one through three retain the
shared exact direct principal test.

## Complete Decision Flow

```text
receive a parser-guaranteed nonempty square symmetric integer matrix A
Q = -A
build the packed negative-entry adjacency of A once
for each support surviving FracESSA pruning, in cardinality order:
    if |S| <= 3 and the exact direct test on A[S,S] fails: return false
    if |S| > 3 and G-(A)[S] is disconnected: skip S
    solve the exact reduced first-order KKT system
    reject singular systems, nonpositive probabilities, and failed outside inequalities
    if a KKT candidate payoff is nonnegative: return false
    add its support as a forbidden rule for later strict supersets
return true
```

A strict matrix can have its largest negative KKT payoff only on a disconnected support, so Level 2 may leave no accepted connected
KKT candidate. That is not an error: all skipped values are still negative in the strict case. A non-strict matrix has a connected
support with a nonnegative witness and therefore a connected global maximizer with nonnegative payoff. Timeout checkpoints propagate
an unresolved result.

## Source Behavior And coposit Changes

Retained from `fracessa` are $Q=-A$, the low-order exact rejection, cardinality-first packed generator, reduced first-order equations,
strict support probabilities, outside inequalities, payoff-sign exit, forbidden-superset pruning, exact LDLT arithmetic, and no
second-order filtering. The only new mathematical rule is the Level 2 skip for disconnected order-four-or-larger supports. Packed
adjacency and reused BFS storage are representation additions.

The model deliberately omits Level 1 input decomposition, ESS or NSS classification, Hadeler determinant tests, Dickinson
certificates, cone subdivision, duplicate-row contraction, and floating proposals.

## Termination And Limits

At most $2^n-1$ supports exist, and every retained operation is finite in exact arithmetic. Packed supports and adjacency have no
fixed-width dimension limit. A complete negative graph defeats Level 2, while sparse graphs may still leave exponentially many
connected induced supports. Large exact systems, large integer coefficients, forbidden-set memory, and recursion depth remain
practical limits.

## Known Difficult Inputs

The model remains difficult when the negative graph is dense, few small supports satisfy the full KKT inequalities, and the first
decisive candidate has large support. Hildebrand circulant boundary forms have large-support zeros and dense enough interaction to
remain challenging. Large arbitrary-precision entries increase exact solve cost independently of the number of supports. Level 2
can also add pure overhead when nearly every generated support is connected.
