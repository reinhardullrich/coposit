# Remaining-Width Dickinson Certificate Threshold Experiment

Status: research result.

The model names below identify the historical binaries used for this run. The maintained code now has one
`wide_certificate_cbdd_dickinson` model whose runtime percentage parameter reproduces the 75%, 90%, and 95% rules.

## Setup

Matrix 12649 is the order-50 BPQY COP construction with designated support size 12 and seed 0. The experiment selected CP mode,
disabled shared preprocessing, retained the model-local Zed scan, and imposed a 60-second native cutoff. The exact materialized
matrix has no confirmed truth field; COP describes the intended BPQY construction.

For a certificate generated at support cardinality $k$, let $d=|U|-|L|$. The three models insert the complete Dickinson interval
$[L,U]$ only when, respectively,

$$
d>\frac34(n-k),\qquad d>\frac9{10}(n-k),\qquad d>\frac{19}{20}(n-k).
$$

A certificate that fails its threshold is still counted below, but only the exact processed support $[I,I]$ is inserted into the
CBDD. Thus the distributions describe every generated certificate, not only the intervals used for pruning.

## Outcomes

All three models timed out. Each had its own solver CPU. The 75% run began approximately 30 seconds before the other two because the
execution policy was changed from sequential to parallel after it had started.
